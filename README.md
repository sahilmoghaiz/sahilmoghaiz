### 🌦️ ClimatePulse — Climate & Air Quality Data Pipeline

A data engineering project focused on weather and air quality data ingestion, streaming, workflow orchestration, and analytics.

- 🌤️ Ingests weather and air quality data using Python APIs.
- 🔄 Uses Apache Kafka for streaming and message ingestion.
- ⚙️ Uses Apache Airflow for workflow orchestration.
- ☸️ Uses Kubernetes to manage containerized workloads.
- 🐳 Uses Docker for containerization.
- ☁️ Integrates cloud analytics with Amazon Athena and Power BI.

**Tech Stack:** Python, Apache Kafka, Apache Airflow, Kubernetes, Docker, AWS.
